# Changelog

All notable changes to BlueSky Café Management System are documented in this file.

## [Unreleased]

### Added
- React and Vite frontend in the `client` directory.
- Express backend in the `server` directory.
- MongoDB connection using Mongoose.
- Dashboard for café management.
- Product Management module.
- Inventory Management module.
- Order Management and Order History modules.
- Sales and Reports modules.
- User Management module.
- User login with password verification using bcrypt.
- User accounts with Staff, Manager, and Administrator roles.

### Changed
- Organized the application into separate frontend and backend directories.
- Added environment-based configuration for the MongoDB connection.

### Notes
- The project is under active development.
- Authentication and role-based authorization may need further hardening before deployment.
